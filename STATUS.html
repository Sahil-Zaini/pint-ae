Decisions I made

You said to decide, so these are settled. Each one follows the official resources ZIP.

Publishing

Done
  • Repo sahilzaini2007-pixel/pint-ae, Composer package zainidevelopers/pint-ae, MIT licence, version 1.0.0.
  • The 14 examples from your test cases are published with the seller renamed and the Complyance emails removed. The TRNs and IBAN are public dummy values.

Your Complyance names are converted to the official codes

Done
  • MONTHLY → MTH, with the full frequency list (DLY, WKY, QTR…).
  • GOODS_OR_SERVICES_RETURNED → DL8.61.1.D, CONSIDERATION_ALTERED → DL8.61.1.C, plus the other four reasons.
  • ELECTRONIC_DEVICES → DL8.48.8.2, plus gold, oil, gas and hydrocarbons.
  • VATEX-AE-ZERO / VATEX-AE-OOS stay as they are. The official examples use VATEX-AE-* codes too, and only exempt (E) lines are tied to the DL8.46.x list.

The three open mappings are settled

Done
  • The Peppol endpoint is the 10-digit TIN, as in every official example. The examples now use 1000000000.
  • The BTAE-20 AED total uses DocumentTypeCode aedtotal-incl-vat, which matches the official files.
  • Margin scheme uses Latin N. The official code list prints a Greek "Ν" by mistake, and the library accepts both.

Added because the resources made it possible

Done
  • Discounts and charges on lines and on the whole invoice, by amount or by percentage.
  • Seller TIN, passport registration with issuing country, and state codes for foreign buyers.
  • A CI job that runs the official Schematron on every push.
